
Learning:
I learned how to maintain data lineage. Instead of overwriting the original data, I added new columns to the 
dataframes. This made them wider, but it preserved the original values. I also learned how to use 
df.apply(lambda row: ..., axis=1) to apply a function to every row of a dataframe. 
Unlike Series.apply(), which only sees the values in a single column, this gives the function access to every 
column in the row. For example, a function that multiplies rate by hours calculates the total pay for one row. 
Applying it to the dataframe creates a new gross_pay column with a value for every row, and I only have to call 
apply once.
