
Learning:
I learned how to maintain data lineage during this assignment by adding columns to the dataframe 
instead of writing over the original data. This made the dataframe wider and wider, but never 
overwrote the original data in case someone else might need it down the line. I learned how to use 
dataframe.apply(lambda row) to apply functions to entire dataframes. This allowed me to create new columns with 
the outputs of the functions using other columns as the parameters of the function.
